# Посмотри в окно

Учебный проект Яндекс Практикума для просмотра городских видео. Фильтры позволяют выбрать город и время суток.

## Запуск

Запустите локальный сервер из корня проекта:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Для загрузки видео требуется доступ к API Практикума.

## Файлы

- `index.html` — разметка страницы и шаблоны карточек.
- `styles/` — стили страницы, индикатора загрузки и сообщения об ошибке.
- `scripts/script.js` — загрузка видео, поиск и переключение роликов.
